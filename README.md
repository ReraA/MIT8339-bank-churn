# MIT 8339 – Customer Retention BI Analysis

Business Intelligence analysis of customer attrition using the Credit Card Customers (BankChurners) dataset.

## Files
- `MIT8339_Bank_Churn.ipynb` – data profiling, cleaning, transformation and analysis
- `BankChurners.csv` – original dataset (Goyal, n.d., Kaggle)
- `BankChurners_Cleaned.csv` – cleaned dataset used in Power BI
- `MIT8339_Dashboard.pbix` – interactive Power BI dashboard (open in Power BI Desktop)
- `MIT8339_Dashboard.pdf` – static PDF export of both dashboard pages

## How to reproduce
1. Install Python with pandas and numpy (e.g. Anaconda).
2. Download the files and open the notebook.
3. In the first cell, change the file path to the folder where you saved `BankChurners.csv`.
4. Run Kernel → Restart & Run All.

## Data source
Goyal, S. (n.d.). *Credit card customers* [Data set]. Kaggle. https://www.kaggle.com/datasets/sakshigoyal7/credit-card-customers
